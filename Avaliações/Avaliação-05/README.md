Criei um cliente HTTP em Dart que acessa o servidor Web da atividade-04 de forma assíncrona. O programa busca todos os alunos cadastrados no servidor, verifica a média e a quantidade de faltas de cada um e informa se ele foi aprovado ou reprovado. Por fim, os alunos são exibidos no formato ID NOME DISCIPLINA MEDIA FALTAS MENSAGEM, com tratamento das condições solicitadas.
