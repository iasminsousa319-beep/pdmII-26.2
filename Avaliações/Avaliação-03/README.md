Criei um programa em Dart que acessa de forma assíncrona um banco de dados SQLite chamado alunos.db. Caso o banco não exista, ele é criado na raiz do projeto. Depois, é criada a tabela tb_alunos, onde são cadastrados três alunos. Por fim, o programa lista os alunos cadastrados na tabela. Todas as operações possuem tratamento de exceções para evitar erros durante a execução.
